# Strata Performance Management System — Phase 1 MVP

A configuration-driven, interactive prototype for Strata Advisory Limited's Performance Management System. Built for the **Strata AI Challenge**, this Phase 1 demonstration validates all core policy rules, organizational reporting lines, score calculations, approval workflows, and audit requirements in a zero-dependency web interface.
